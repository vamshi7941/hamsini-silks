# Hamsini Server

This is a minimal TypeScript + Express backend for the Hamsini frontend.

Quick start:

Install dependencies:

```
cd server
npm install
```

Run in development (auto-reloads):

```
npm run dev
```

Available endpoints:

- `GET /api/health` — health check
- `GET /api/products` — list sample products
- `GET /api/products/:id` — product detail
